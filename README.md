# ⛏ Modpack Builder

Локальный конструктор сборок Minecraft: собирает моды, датапаки, шейдеры и ресурспаки
с [Modrinth](https://modrinth.com) в одну сборку и выгружает её в `.mrpack`.

Работает целиком на твоём компьютере: данные никуда не отправляются, наружу уходят
только запросы к официальному API Modrinth.

---

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt     # Windows
python app.py
```

Или просто двойной клик по **`start.bat`**.

Браузер откроется сам на <http://localhost:7842> — ровно тогда, когда сервер уже
принимает соединения (никаких «сайт недоступен» при старте).

Полезные ключи:

| Ключ | Что делает |
|---|---|
| `--port 8080` | другой порт (по умолчанию 7842) |
| `--no-browser` | не открывать браузер автоматически |
| `--host 0.0.0.0` | слушать не только localhost |

Если приложение уже запущено, повторный запуск не падает с ошибкой, а просто
открывает вкладку с работающим экземпляром.

## Что умеет

* Добавление по ссылке на Modrinth или по slug (`sodium`, `https://modrinth.com/mod/sodium`).
* Автоматический подбор совместимой версии Minecraft по большинству модов.
* Фильтр по загрузчику (Fabric / Forge / NeoForge / Quilt), поиск по коллекции.
* Экспорт `.mrpack` — файлы раскладываются по своим папкам:

  | Тип проекта | Папка в сборке |
  |---|---|
  | мод | `mods/` |
  | плагин | `plugins/` |
  | датапак | `datapacks/` |
  | шейдер | `shaderpacks/` |
  | ресурспак | `resourcepacks/` |

* Экспорт / импорт JSON-списка коллекции.
* Кнопка **⟳ Метаданные** — заново подтягивает версии MC и загрузчики для всех модов.
* Живая синхронизация: мод, добавленный из расширения, сразу появляется в открытой
  вкладке приложения (и наоборот) — через Server-Sent Events.

### Почему быстро

* Ответы Modrinth API кэшируются в памяти (проект — 6 часов, список версий — 10 минут).
* Все запросы идут через один `requests.Session` с keep-alive, ретраями и склейкой
  одновременных одинаковых запросов.
* Массовые операции параллельные: экспорт сборки из 30 модов — это 30 параллельных
  запросов, а не 30 последовательных; повторный экспорт берётся из кэша.
* Коллекция живёт в памяти, на диск пишется атомарно (временный файл + `os.replace`),
  поэтому параллельные запросы ничего не теряют и файл не бывает «полузаписанным».
* `/api/collection` отдаёт `ETag`: интерфейс и расширение при повторе получают `304`
  без тела, а ответы сжимаются gzip.
* Интерфейс не перерисовывает список целиком — карточки обновляются точечно,
  поэтому иконки не перезагружаются и ничего не мигает.

## Расширение для Chrome

Папка `modpack_extension/` — распакованное расширение (Manifest V3).

Установка: `chrome://extensions` → включить **Режим разработчика** → **Загрузить
распакованное** → выбрать папку `modpack_extension`.
После обновления файлов нажми **↻ Обновить** на карточке расширения. В версии 2.1
добавлено право `contextMenus` (пункт правого клика) — Chrome может попросить
включить расширение заново, это нормально.

Что оно делает:

* **значок `+ ⛏` на карточках** в поиске и списках Modrinth (и `✓`, если мод уже в сборке);
* **кнопка «Добавить»** внизу справа на странице проекта;
* **правый клик** по ссылке или по странице → «Добавить в Modpack Builder»;
* **горячая клавиша** `Alt+Shift+M` — добавить открытую страницу проекта;
* **счётчик модов** на иконке расширения;
* **удаление** прямо со страницы, с кнопкой **«Отменить»** в уведомлении;
* **⚙ настройки** — если приложение запущено на другом порту, укажи его там
  (по умолчанию `http://localhost:7842`);
* при закрытом приложении расширение показывает офлайн-виджет и само подхватывает
  связь, когда ты запускаешь `app.py` — перезагружать страницу не нужно.

## Где лежат данные

`%USERPROFILE%\.modpack_builder\collection.json`

Если файл повреждён, он не удаляется, а переименовывается в `collection.json.bak`,
а приложение продолжает работать с пустой коллекцией.

Переопределить расположение можно переменной окружения:

```bat
set MPB_DATA_FILE=D:\modpacks\my_collection.json
python app.py
```

## Структура проекта

| Файл | Назначение |
|---|---|
| `app.py` | backend: Flask + Modrinth API, кэш, экспорт, SSE |
| `templates/index.html` | разметка веб-интерфейса |
| `static/app.css` | стили интерфейса |
| `static/app.js` | логика интерфейса (точечное обновление DOM, SSE) |
| `modpack_extension/` | расширение для браузера |
| `start.bat` | запуск двойным кликом |
| `modpack.json` | пример экспорта коллекции (можно загрузить кнопкой «Импорт JSON») |

> `modpack_extension.crx` — тот же код, упакованный в один файл (пересобран под
> версию 2.1). Установить `.crx` в Chrome на Windows обычно нельзя без политики
> предприятия, поэтому надёжный способ — загрузить распакованную папку
> `modpack_extension/`. Файл `modpack_extension.pem` — приватный ключ, которым
> подписан `.crx`; храни его, если будешь пересобирать пакет.

## API (для расширения и своих скриптов)

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/ping` | мгновенная проверка живости: `{ok, api, revision, mods}` |
| `GET` | `/api/collection?loader=&version=` | коллекция + совместимые версии + статистика; поддерживает `If-None-Match` |
| `GET` | `/api/events` | SSE-поток изменений коллекции |
| `POST` | `/api/add` | `{"url": "ссылка или slug"}` |
| `POST` | `/api/remove` | `{"slug": "..."}` |
| `POST` | `/api/clear` | очистить коллекцию |
| `POST` | `/api/refresh` | перечитать метаданные всех проектов |
| `POST` | `/api/export/mrpack` | `{"version": "1.21.1", "loader": "fabric"}` |
| `GET` | `/api/export/json` | выгрузка списка |
| `POST` | `/api/import/json` | загрузка списка |

## Если что-то не так

* **«Порт 7842 занят другой программой»** — запусти `python app.py --port 8080`
  и укажи этот адрес в настройках расширения (⚙).
* **«Modrinth недоступен»** — приложение покажет данные из кэша; проверь интернет.
* **Иконки модов не грузятся** — они берутся с `cdn.modrinth.com`; без интернета
  вместо них показывается заглушка 🧩.
* **Расширение не видит приложение** — убедись, что `app.py` запущен, и нажми
  «Проверить связь» в ⚙ настройках расширения.
