⛏ Modpack Builder — настройки

Расширение добавляет моды, датапаки, шейдеры и ресурспаки с Modrinth в локальную сборку одним кликом.
Адрес приложения
Приложение по умолчанию слушает localhost:7842. Если порт занят, запусти его иначе — python app.py --port 8080 — и укажи здесь тот же адрес.
Горячая клавиша
Alt+Shift+M — добавить открытую страницу проекта в сборку. Изменить сочетание можно на странице управления расширениями.
Как пользоваться
• На странице проекта внизу справа появляется кнопка «Добавить».
• В списках и поиске у каждой карточки — значок + ⛏.
• Правый клик по ссылке или по странице → «Добавить в Modpack Builder».
• Клик по иконке расширения открывает список коллекции.
